`gallery-dl --extractor-info` for twitter.tweet extractor:

```
Category / Subcategory
  "twitter" / "tweet"

Filename format (default):
  "{tweet_id}_{num}.{extension}"

Directory format (default):
  ["{category}","{user[name]}"]

Archive format (default):
  "{tweet_id}_{retweet_id}_{num}"
```

----


The keyword 'count' returns the number of media items within a single tweet.
The keyword 'num'   returns which item number of media.
