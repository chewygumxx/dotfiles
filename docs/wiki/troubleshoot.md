# Troubleshoot

[Docs Home](./../README.md)

<!-- TODO(@chewygumxx): Finish whatever this was intended to be -->

Each heading is a symptom a person would be expected to search for. Beneath
each include

- **Cause**: Reproducible environment and events necessary to trigger issue.
- **Diagnosis**: Assessment criteria for unique identification.
- **Prevention**: Mitigation practice
- **Solution**: Active response procedure
- **State** and the **Evidence**. The state
  is one of three, and the entry never blurs them:

- **Resolved Defect**: it was a fault and a fix is recorded, with its report or
  commit.
- **Known Limitation**: the behaviour is understood and left as it is, by design
  or for later; a record says so.
- **Workflow Pitfall**: nothing in the code is wrong; working in or on the
  repository goes astray in a known way.
